# @sleinity/template-react 2.0.0

React 19 V2 bindings, mounted session rendering and guarded PNG export. Part of the fixed-version SDK train for Sleinity-owned applications. Verify the supplied delivery provenance; version labels alone do not establish publication.

Start with [host onboarding](https://github.com/Sleinity/template-tool/blob/f85741a7fbe185dad31484590cdf0906e6932f07/docs/sdk/QUICKSTART.md), [the feature guide](https://github.com/Sleinity/template-tool/blob/f85741a7fbe185dad31484590cdf0906e6932f07/docs/sdk/FEATURES.md) and [supported entries](https://github.com/Sleinity/template-tool/blob/f85741a7fbe185dad31484590cdf0906e6932f07/docs/sdk/API_GUIDE.md). Typical entry: `@sleinity/template-react/editor`. Runtime hosts install all three packages at the same verified version. Core-only consumers need no React.

ZIP admission accepts raw source schema 1.0/exporter 0.6.1 only; canonical packages use schema 2.2. V1 host workflows are retired; required versioned source/evidence contracts remain. No hidden migration or historical-data deletion is provided.

Use public package entries, never Studio, package source or internal entries. Hosts own UI, navigation and disposal; native sessions and the renderer preserve existing resource/readiness authorities. See [ownership](https://github.com/Sleinity/template-tool/blob/f85741a7fbe185dad31484590cdf0906e6932f07/docs/sdk/HOST_LIFECYCLE.md), [outcomes](https://github.com/Sleinity/template-tool/blob/f85741a7fbe185dad31484590cdf0906e6932f07/docs/sdk/OPERATION_OUTCOMES.md) and [release notes](https://github.com/Sleinity/template-tool/blob/f85741a7fbe185dad31484590cdf0906e6932f07/docs/sdk/SDK_2_0_RELEASE_NOTES.md).

Repository links pin the reviewed host contract. The complete delivery also contains the current guides as `SDK-*.md`, so installed-package users need no repository checkout.
