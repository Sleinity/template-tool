# V2 SDK host example

This example mounts the shared [Field Rules V2 host](FieldRulesV2Host.tsx). It accepts exporter 0.6.1 ZIPs and uses native V2 single/Family sessions, typed controllers, fonts, images, recovery and guarded PNG export. There is no V1 compatibility route.

See [integration](SDK-V2-INTEGRATION.md) and [lifecycle](SDK-HOST-LIFECYCLE.md). Build with `pnpm example:build`.
