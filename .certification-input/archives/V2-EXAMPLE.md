# Complete V2 editing host

> Unpublished local candidate 2.0.0. Not published or certified by packing. Do not mix it with published archives carrying the same version.

Unzip [SDK-HOST-STARTER.zip](SDK-HOST-STARTER.zip), copy this delivery’s three archives into vendor/, and follow [onboarding](SDK-QUICKSTART.md). The standalone project includes source, styles, exact dependency closure, React 19, TypeScript and Vite configuration.

One ZIP opens a single template; multiple prepared sources open a native Family. Exact fonts, typed controls, Choices, replacement/crop demonstration, Reset, Save/reopen, Fresh/Resume/Discard, 650 ms host-owned recovery autosave and guarded PNG are included. Cleanup-only Retry never exports twice.

[CompleteHost.tsx](CompleteHost.tsx) and [starterPersistence.ts](starterPersistence.ts) compose public SDK entries with the staged [font/import lifecycle](fieldHostLifecycle.ts). [FieldRulesV2Host.tsx](FieldRulesV2Host.tsx) remains a focused single-source example. All helper code is private example composition, not a new SDK API.
