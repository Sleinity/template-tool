# Property-Authority Inventory

## Borrowed host font authority (ADR 0096)

The host chooses the registry; existing font preparation and semantic matching decide exact authority. Native sessions retain publication acceptance and readiness. A private committed React scope rejects abandoned registry/session/mount work; it does not promote stale line observations or change settlement ownership. PNG clones require the same authority's exact bytes.

A private immutable package shell renews the existing child-renderer publication
generation when its committed lease changes. It preserves canonical data and
mounted measurement caches; current dependency validation precedes republication.

## Existing media underlay diagnostics (ADR 0095)

The existing CSS background/media owners retain source SOLID → IMAGE order for
the bounded opaque NORMAL FILL/FIT pair. Primitive SVG ineligibility remains
technical evidence rather than an active media fallback. Resolved-node diagnostics
decide applicability; backend projection remains the user-facing classification
authority. No paint, geometry, asset, mask or readiness authority changes.

## Mounted text inputs and publication

ADR 0093 separates private mounted-input validity from publication freshness. Existing Range/Canvas calibration supplies intrinsic input; bounded settlement owns routed geometry and native sessions own evidence acceptance. Connected refs, complete typography/run/font/constraint inputs and current generation are independently required.


## Observational mask-range delegation (2026-10-07, ADR 0092)

`resolvePackageMaskRelationships` remains the mask capability and canonical clip
authority. Optional inspection input delegates to that result and preserves the
matching scene-declared source, parent, ordered sibling scope, mask revision,
source bounds, affected clip insets and provenance. It does not measure alpha,
choose another visual owner or make the observational graph render-authoritative.
Current measurement revision checks remain mandatory. Source semantics/bounds,
parent declaration/order and affected bounds invalidate range, clip, diagnostics
and export evidence; unknown property changes use the existing full-tree policy.
No production property authority changes in this milestone.

## Bounded mixed paint and HUG text authority (2026-10-07)

ADR 0091 gives the exact, source-indexed opaque SOLID → FILL IMAGE → DARKEN
linear-gradient stack one visual owner on a static, opaque direct FRAME. The
existing media placement and certified gradient geometry remain property
authorities; the mixed owner only composes them in source order and disables
the duplicate compatibility fill. Other mixed stacks retain compatibility.

For horizontal HUG text, the exported source width is the initial geometry
evidence. Browser intrinsic measurement supplies edit-time width, but CSS's
terminal letter-spacing contribution is removed so the measured box reflects
gaps *between* glyphs. The same measurement lifecycle handles initial and
edited text. Exact 0.6.1 Now Hiring 306/405 px source widths measured at
305.6/404.7 px after this correction.

## Bounded opaque compositing authority (ADR 0090)

For source-certified exporter 0.6.1 Matrix rows and Matrix 2 groups,
`ResolvedSourceCompositingV1` reads exact canonical SOLID paint order, color,
opacity, blend, and group mode/opacity. The backend decision selects one DOM
paint-layer owner across every surface and PNG, suppressing the former singular
background owner. PASS_THROUGH exposes the external backdrop; NORMAL isolates;
OVERLAY isolates then blends the group. Non-overlapping rows and an opaque
canvas are required. Unsupported property combinations keep one coherent
compatibility owner and an explicit fallback. The historical inventory rows
below predate this bounded transfer; no general IMAGE/gradient compositing
authority is implied.

## Field Rules V2 authoring authority

Studio owns uncommitted configuration UI drafts only. Core validates portable
rules/order and reconciles canonical content; Browser `configure()` transactions
retain assets and drive one materialization. Typed controllers remain the normal
content mutation path. The React session bridge owns current renderer evidence
and export gating. No field configuration control, custom host palette, or crop
UI owns renderer geometry or reconstructs canonical content.

## Renderer rollout authority

Renderer mode is an internal operational preference, not an imported property. Raw and canonical authority are absent; `PersistedRendererRolloutPreferenceV1` owns the requested global mode, `ResolvedRendererRolloutDecisionV1` owns effective mode and selected visible owners, and family contracts remain semantic authority for capability eligibility. Missing or corrupt preference state safely defers to the existing surface default. Export consumes the same rollout decision and persistence identity as the visible renderer.

“Current” records existing pixel behavior. Milestone 4 migrates a bounded core layout/text family to explicit runtime ownership while retaining coherent compatibility routing. Enrichment remains lower priority than explicit canonical/user data.

For routed core subtrees, `CoreLayoutSettlementV1` owns final x/y/width/height, supported Auto Layout, parent HUG, sibling FILL, image-slot, rectangular clip, and export-root geometry on every live surface. The browser owns only revision-tagged intrinsic text metrics. Fields and Validate retain static compatibility appearance while applying eligible settled core geometry; masks, transforms, complex constraints, circular FILL-in-HUG, and advanced visual families remain compatibility-owned. See [runtime routing](RUNTIME_ROUTING.md), [surface convergence](SURFACE_CONVERGENCE.md), and ADRs 0025–0030.

Milestone 5 appearance contracts are observational projections of canonical candidates and provenance, not new live owners. Masked sibling ranges, offscreen compositing, and backend selection remain unresolved rather than inferred.

Milestone 6 makes `ResolvedImagePlacementIntentV1` the current runtime authority for image fit/crop interpretation. Routed settlement or coherent compatibility still owns the slot; the pure placement resolver owns source/destination geometry; the browser owns only native sampling. See [image placement](IMAGE_PLACEMENT.md) and ADR 0047.

Milestone 7 adds a narrow source-certified mask authority. Strict `node.mask.isMask=true` and package `maskRelationships` own classification and sibling scope; the current resolved mask revision owns exact opaque-rectangular ALPHA lowering; the source fill is semantic `mask-input`, not ordinary RGB output. A source-certified full-parent scope uses the parent clip boundary on every surface so live HUG changes cannot retain stale affected-node insets. Unsupported mask types, paints, transforms, geometry, or relations remain explicit compatibility states. See [mask authority](MASK_SOURCE_CONTRACT.md) and ADRs 0050–0052 and 0084.

Milestone 7.1 adds `PrimitiveAppearanceV1` as the sole runtime visual owner for its capability-selected rectangular subset. Canonical scene properties own semantic intent; current settled bounds own effective radius/stroke geometry; resolved source/geometry/paint/stroke revisions gate publication. Unsupported primitive properties select coherent compatibility instead of split output. See [primitive authority](PRIMITIVE_PAINTS.md) and ADRs 0053–0056.

Milestone 7.2 transfers independent rectangular corners and opaque uniform `CENTER`/`OUTSIDE` stroke geometry to the same bounded primitive owner after receipt of the exact source fixture. Canonical values own intent; current settled bounds own edge-local effective radii and stroke-path geometry; backend selection is singular and capability-based. See [the closed fixture gate](PRIMITIVE_STROKE_FIXTURE_GATE.md), [stroke geometry contract](PRIMITIVE_STROKE_GEOMETRY.md), and ADRs 0057–0061.

Milestone 7.3A transfers only the closed source-certified linear-gradient subset. Same-index `extensions.figma.rawFills` hydrates strict canonical stops/transform with provenance and conflicts; `ResolvedLinearGradientGeometryV1` owns one-inverse normalized geometry and current-bounds SVG geometry; one SVG primitive owns pixels. Stops, stop alpha, paint opacity, node opacity, and source-over remain separate authorities. See [runtime authority](LINEAR_GRADIENT_RUNTIME_AUTHORITY.md) and Accepted ADR 0063.

## Decisions retained as unresolved for later milestones

- Whether editable-field defaults or imported node values are the normative imported default when they disagree.
- Raw Figma promotion into the scene is now explicit, but removal from current runtime helpers remains gated by [the migration map](SCENE_MIGRATION.md).
- Browser measurements are runtime intrinsic inputs for the Milestone 4 core route; final DOM bounds remain compatibility evidence only.
- Whether canvas or root bounds win on mismatch and how that is diagnosed.
- Source FILL/FIT and affine CROP plus editor replacement Fill/Fit are migrated. Fixed FILL no longer consumes CROP-only matrices. Interactive editor crop, TILE, adjustments, and true masks remain unresolved.
- Mask range/bounds semantics, compositing groups, variables, component overrides, and style identity.
- How one settled instance is shared across static inspection and live/export surfaces remains Proposed ADR 0010. Editor and hidden PNG share a deterministic revision/identity; Fields/Validate intentionally remain bounds-first compare surfaces.

## Changed text measurement timing — ADR 0094

Fresh browser intrinsic cap-trim metrics may complete in the current layout effect with
known face/constraint inputs. Applying HUG width/trim validates the resulting
mounted inputs again. This does not authorize DOM parent/sibling boxes as routed
geometry, preserve old metrics for changed text, or weaken native publication and
PNG-readiness guards. Studio reduced-motion CSS must not introduce a transition
between two template geometry states. See [ADR 0094](decisions/0094-fresh-text-measurement-before-paint.md).
