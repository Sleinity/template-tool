## Highest-risk duplications

The immediate architectural risks remain: (1) static snapshot versus editor dynamic geometry outside the routed family, (2) resolved-tree values versus raw runtime fallbacks, (3) fixed ambiguous FILL matrices without reviewed source references, and (4) export readiness/capture recreating graphs around a separately mounted DOM. Milestone 6 retires the competing dynamic-FILL crop interpretation but intentionally does not hide the fixed compatibility boundary.

The previous upload-candidate versus final font-validation duplication is no longer active: both paths call `matchCanonicalFontFace`. Remaining font duplication is intentional evidence layering—semantic match, binary registration, browser readiness, and revision-tagged measurement answer different questions.
