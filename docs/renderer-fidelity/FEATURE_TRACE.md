Paths are repository-relative. “Raw” refers to exporter JSON or ZIP members; “canonical” means strict `TemplatePackageV1`; “resolved” means `ResolvedRenderTreeV1`. Support claims require a runtime path, not only a type.

## Source-data gaps observed

- Several advanced capabilities can be represented by Figma but are absent from current strict canonical semantics or survive only under `extensions`.
- Type availability does not demonstrate exporter population; the external fixtures must be used by Milestone 1 to record actual property presence.
- Gradient-test-3 and gradient-test-4 are now registered gradient fixtures. Effects/blend-heavy, rich-text, vector-heavy, and component/variables coverage remain absent or incomplete.
- No settled graph records browser-measured HUG height, final line boxes, decoded intrinsic asset state, or post-edit ancestor invalidation.
