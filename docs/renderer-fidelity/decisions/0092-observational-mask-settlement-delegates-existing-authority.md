# ADR 0092: Observational mask settlement delegates existing authority

Status: Accepted for observational evidence only  
Date: 2026-10-07

## Context

The active exporter 0.6.1 Carrousel source declares one rectangular ALPHA mask.
Canonical and resolved projections already retain its exact scope and CSS clip
authority. The observational settlement engine nevertheless marked every mask
range unresolved, blocking all four bundles without a demonstrated pixel defect.
Colon-containing source IDs were also truncated in dependency vertex metadata
and invalidation. Random output-route template IDs made cross-run measurement
snapshots differ independently of geometry.

## Decision

The optional settlement input `maskResolution` carries the existing
`resolvePackageMaskRelationships` result. The observational projection accepts
only matching current scene/resolution identity, revision, source, parent,
ordered affected siblings, geometry, exact rectangular ALPHA capability and
supported termination. It retains canonical source bounds, affected insets and
provenance. It does not implement a competing classifier, visual owner or final
DOM clip authority. Unsupported, absent or mismatched evidence stays unresolved.
Existing complete measurement-revision publication remains mandatory.

Declared mask dependencies connect source semantics/geometry, parent ordering
and affected geometry to range, clipping, diagnostics and export evidence.
Vertices and invalidation use full source IDs. Unknown properties use the
documented full-tree fallback. Snapshot normalization removes volatile output
template IDs while preserving template kind and route role.

Settlement promotion preflights complete matching bundles and rejects unstable,
pending, unresolved or non-equivalent evidence before modifying references.
Updates remain explicit, reasoned and bound to the reviewed capture run.

## Compatibility and limits

The inspection contract gains optional authority input and resolved mask evidence;
existing callers without it retain conservative unresolved masks. Export names,
canonical schemas, session APIs, persistence, renderer pixels and source color
values do not change. The full observational settled graph is still test-only.
ADRs 0010 and 0012 remain Proposed. Exact range evidence does not establish
general mask compositing, nested/partial-alpha support or independent prediction
of all browser geometry.

## Verification

See [the contract and current evidence](../OBSERVATIONAL_MASK_SETTLEMENT.md).
Contract tests exercise current/missing/stale/unsupported authority, scope,
geometry, edits, resize, full IDs, invalidation, revision rejection and repeat
serialization. Real source tests bind hash-verified ZIP declarations to the
existing resolver and all four recorded browser clip identities. Renderer and
scene comparisons remain independent of settlement approval.
