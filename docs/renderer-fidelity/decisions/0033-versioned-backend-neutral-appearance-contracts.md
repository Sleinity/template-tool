# ADR 0033: Use versioned backend-neutral appearance contracts

## Status

Accepted

## Context

Media, geometry, paints, strokes, masks, effects, and compositing need authority contracts before routing.

## Evidence

The canonical scene preserves ordered source evidence, but registered fixtures lack advanced-family coverage.

## Decision

Project the seven V1 contracts observationally with source paths, raw keys, confidence, sufficiency, and backend requirements. Runtime use remains disabled.

## Alternatives

Renderer-specific CSS objects and premature Canvas/WebGL selection were rejected.

## Consequences

Future routing has stable inputs; missing sibling ranges and backend needs remain explicit.

## Compatibility impact

No renderer, schema, import, or export behavior changes.

## Migration impact

Each family requires fixture-led acceptance before it can become authoritative.

## Verification

Determinism, validation, ordering, real-ZIP projections, and production-bundle exclusion.

## Reversal strategy

Delete the observational projection without data migration.
