# Complete SDK 2.0.0 editing host

Run the React/TypeScript starter with one ZIP for a single template or multiple sources for a native Family. Exact font preparation and staged acceptance preserve the active editor on failure. Typed controls, Choice identity, image replacement/crop demonstration and Reset use public controllers. Save template enables browser-local recovery; Fresh/Resume/Discard and 650 ms host-owned autosave are separate from SDK behavior. PNG uses current renderer readiness and cleanup-only Retry.

See [onboarding](../../docs/sdk/QUICKSTART.md), [implementation](../../docs/sdk/HOST_IMPLEMENTATION.md), [features](../../docs/sdk/FEATURES.md) and [ownership](../../docs/sdk/HOST_LIFECYCLE.md). The delivered `SDK-HOST-STARTER.zip` is standalone and uses verified vendored package archives. No Studio/internal imports or private ZIP/font inputs are included.

In the monorepo run `pnpm example:build`. For a standalone application follow the delivered install/run instructions and use its generated package manifest/overrides rather than workspace dependencies. The minimal renderer remains a smaller single-source example.
